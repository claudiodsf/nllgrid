# NLLGrid

Python class for reading and writing NonLinLoc grid files.

Copyright (c) 2015-2026 Claudio Satriano, Natalia Poiata, Robert Pickle

---
NLLGrid is an open-source Python package for reading, writing, and manipulating
NonLinLoc grid files used in seismological workflows.

Source code:
[github.com/claudiodsf/nllgrid](https://github.com/claudiodsf/nllgrid)

Documentation:
[nllgrid.readthedocs.io](https://nllgrid.readthedocs.io)

If you use NLLGrid in your work, please cite:

> Satriano, C., Poiata, N., & Pickle, R. (2026). NLLGrid: Python class for
> reading and writing NonLinLoc grid files (X.Y).

Replace X.Y with the specific NLLGrid version number used in your study.
